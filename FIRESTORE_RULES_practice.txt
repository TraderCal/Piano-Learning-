PRACTICE LOG — FIRESTORE SETUP
================================

Two things need to be added in the Firebase Console before the practice log works.


─────────────────────────────────────────────
1. COMPOSITE INDEX  (required — query will fail without it)
─────────────────────────────────────────────

The practice log queries by studentUid AND sorts by date, which Firestore
needs an index for.

EASIEST WAY: Just open the portal, click the "Practice Log" tab, and open
your browser console (Cmd+Option+J). Firebase prints an error with a direct
link — click it, then click "Create Index." Takes ~1 minute to build.

MANUAL WAY: Firebase Console → Firestore Database → Indexes → Create Index
  Collection ID:  practice
  Field 1:        studentUid    Ascending
  Field 2:        date          Descending
  Query scope:    Collection


─────────────────────────────────────────────
2. SECURITY RULES
─────────────────────────────────────────────

Firebase Console → Firestore Database → Rules

Add the `practice` block below to your existing rules. Replace
YOUR_TEACHER_UID with your own Firebase Auth UID (find it under
Authentication → Users → your account → User UID).

    match /practice/{entryId} {
      // Students read + write only their own entries
      allow read: if request.auth != null
                  && (resource.data.studentUid == request.auth.uid
                      || request.auth.uid == 'YOUR_TEACHER_UID');

      allow create: if request.auth != null
                    && request.resource.data.studentUid == request.auth.uid;

      allow delete: if request.auth != null
                    && resource.data.studentUid == request.auth.uid;

      // Nobody edits entries after the fact — keeps the log honest
      allow update: if false;
    }

WHAT THIS DOES:
  • A student can only see and log their own practice
  • You (teacher UID) can read every student's log
  • Entries can't be edited after creation, only deleted by their owner
  • Nobody can write an entry under someone else's name


─────────────────────────────────────────────
DATA SHAPE
─────────────────────────────────────────────

Collection: practice
  studentUid  string     Firebase Auth UID of the student
  date        string     "YYYY-MM-DD" (local date, no timezone drift)
  minutes     number     1–600
  notes       string     what they worked on
  createdAt   timestamp  server timestamp

VIDEO LIBRARY — ADDITIONAL RULE
═════════════════════════════════════════════

Videos are assigned per student, same as lesson recaps.

RULE — add alongside the others:

    match /library/{videoId} {
      // Student sees only videos assigned to them; you see all
      allow read: if request.auth != null
                  && (resource.data.studentUid == request.auth.uid
                      || request.auth.uid == 'IUKVOreLZsSkUkbhgFBq8e6Rc532');

      // Only you can add, edit, or remove videos
      allow create, update, delete: if request.auth != null
                                    && request.auth.uid == 'IUKVOreLZsSkUkbhgFBq8e6Rc532';
    }

INDEX — required (same shape as the practice index):

  Firestore Database -> Indexes -> Create Index
    Collection ID:  library
    Field 1:        studentUid    Ascending
    Field 2:        createdAt     Descending
    Query scope:    Collection

DATA SHAPE
  Collection: library
    studentUid   string     Firebase Auth UID of the assigned student
    title        string     video title
    youtubeUrl   string     full YouTube URL (watch, youtu.be, embed, or shorts)
    category     string     Technique | Theory | Voicings | Improv | Repertoire | Other
    description  string     optional blurb
    createdAt    timestamp  server timestamp

DOCUMENTS — ADDITIONAL RULE + INDEX
═════════════════════════════════════════════

PDFs are stored as base64 inside the Firestore doc (same approach as
lesson recap attachments). 700KB per file — the uploader enforces it.

RULE:

    match /documents/{docId} {
      allow read: if isTeacher()
                  || (request.auth != null && resource.data.studentUid == request.auth.uid);
      allow create, update, delete: if isTeacher();
    }

INDEX:

  Firestore Database -> Indexes -> Create Index
    Collection ID:  documents
    Field 1:        studentUid    Ascending
    Field 2:        createdAt     Descending
    Query scope:    Collection

DATA SHAPE
  Collection: documents
    studentUid   string     Firebase Auth UID of the assigned student
    name         string     original filename
    size         number     bytes
    dataUrl      string     base64 data URL of the PDF
    createdAt    timestamp  server timestamp
